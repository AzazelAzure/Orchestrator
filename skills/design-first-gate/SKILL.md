# Design First Gate

Prevents dispatch on incomplete or false-premise designs.

## Procedure

1. Apply trust-but-verify to the plan's stated design status against actual design notes (or their absence) — not the registry row alone.
2. If incomplete: list open questions (premises, scope, architecture) and walk them with the designated human authority one at a time.
3. Record resolved decisions and rationale in the plan-local design note.
4. Align task files to the closed design; retire superseded tasks with an explicit note.
5. Only then update plan readiness state and hand off to the sequencing/dispatch procedure. This skill does not dispatch implementation.

## Outputs

Design closed | design blocked with open questions | superseded tasks listed.
