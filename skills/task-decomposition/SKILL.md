# Task Decomposition

## Procedure

1. Restate the objective and acceptance criteria.
2. Identify gates, dependencies, and evidence required for completion.
3. Slice into packets that fit one department×position loadout each.
4. Declare expected write sets, report paths, and review requirements.
5. Prefer immediate-lower delegation; record skip-level reasons when used.
6. Do not broaden authority or imply provider identity grants capability.
