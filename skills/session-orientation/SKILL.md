# Session Orientation

Thin session-start floor. Do not front-load all governance; phase procedures load their own doctrine at point of use.

## Procedure

1. Resolve installation, project, task, and role via the configured discovery mechanism.
2. Note pre-existing workspace claims, dirty state, and coordination blockers using the configured status interface (logical capability — not a product tool name).
3. Confirm branch and change-publication conventions for anything this session will create.
4. Note that bootstrap/reading-order rules exist; do not re-read the entire baseline here.
5. Hand off to the task-specific procedure that matches the actual work.

## Non-goals

- Do not execute lease/claim/release primitives from this package (engine/adapter).
- Do not invent project facts when discovery is incomplete — enter degraded mode.
