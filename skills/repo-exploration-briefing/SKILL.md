# Repo Exploration Briefing

Breadth-first mapping before planning.

## Procedure

1. Define question scope and target repository set.
2. Map key modules, entry points, and ownership boundaries.
3. Trace main data/control flow for the question.
4. Capture unknowns and ambiguous ownership; label assumptions.
5. Recommend next action (which procedure or planning gate) without product design proposals.

## Guidance

- Prefer the smallest file set that yields confidence.
- Do not deep-dive before scope is clear.
