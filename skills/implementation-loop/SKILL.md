# Implementation Loop

## Procedure

1. Read packet acceptance criteria and write-set bounds.
2. Implement the smallest coherent change.
3. Run targeted verification, then broader suite as required.
4. Record evidence and anomalies; prepare packet-only handoff for review.
5. Do not act as independent reviewer for this same work item/invocation.
