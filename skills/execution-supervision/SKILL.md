# Execution Supervision

## Procedure

1. Confirm assignment, grant, and pinned loadout before supervising.
2. Require packet-only handoffs; reject ambient conversation context.
3. Block self-review and shared implementation/review seat or invocation.
4. On failure, triage recovery without automatic paid retry.
5. Accept child evidence before allowing parent closure.
